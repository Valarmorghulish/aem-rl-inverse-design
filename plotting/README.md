# Plotting scripts

This directory contains the Python scripts used to generate the manuscript
figures for the AEM-RL inverse-design study. The scripts retain the plotting
parameters used for the reported figures, including axis limits, colours,
filtering rules, smoothing factors, and export resolution.

The scripts are supplementary analysis code. They are separate from the model
training and reinforcement-learning implementation in the repository root.

## Contents

| Script | Figure or analysis |
| --- | --- |
| `figures/data_overview.py` | Conductivity/SR distributions, Pareto front, and stability bubble panel |
| `figures/generate_model_distributions.py` | Eight-generator conductivity and SR distributions |
| `figures/compare_rl_models.py` | Pretrain, Fine-tune, PAP, PBF, and PPO comparison |
| `figures/compare_polymer_families.py` | PAEK, PAEKS, and PAES comparison |
| `figures/rl_property_distributions.py` | RL property distributions by polymer family |
| `figures/rl_iteration_distributions.py` | RL iteration distributions |
| `figures/pareto_front.py` | Generated-candidate Pareto fronts |
| `figures/predictor_evaluation.py` | Five-fold predictor evaluation and parity plots |
| `figures/predictor_attention.py` | Final-layer averaged attention map |
| `figures/candidate_tsne.py` | Candidate and training-set t-SNE projections |
| `figures/stability_classifier.py` | Stability classifier ROC, confusion matrix, and pass-rate panels |
| `figures/synthetic_accessibility.py` | Synthetic-accessibility score distributions |

Five figures in the figure inventory were assembled outside the available
Python or notebook sources. Scripts are not provided for those panels.

## Inputs

The scripts expect data and model artifacts generated by the main AEM-RL
workflow, for example:

```text
Conductivity_data_merged_processed.csv
generated_8models_500pairs_full_pipeline/
generated_aem_pairs_strict_all_models_with_predictor/
rl_replay_plots_50PAEK/
rl_replay_plots_50PAEKS/
rl_replay_plots_50PAES/
local_models/polyBERT/
checkpoints/
```

Large datasets, checkpoints, model weights, and RDKit fragment tables are not
tracked in this directory. Follow the main repository data-availability
instructions before running the corresponding script.

## Configuration

Scripts resolve the project root from `AEM_RL_ROOT`. If it is not set, they use
the repository root relative to this directory. Output files are written under
`outputs/figures` by default. Override the output root with
`AEM_RL_FIGURE_OUTPUT`.

Examples:

```bash
export AEM_RL_ROOT="<repository-root>"
export AEM_RL_FIGURE_OUTPUT="<figure-output-directory>"
python plotting/figures/compare_rl_models.py
python plotting/figures/pareto_front.py
```

The predictor and t-SNE scripts additionally accept `AEM_RL_POLYBERT`; the
stability scripts accept `AEM_RL_STABILITY_CSV` or
`AEM_RL_STABILITY_RESULTS` when artifacts are stored outside the default layout.

## Dependencies

Install the main repository requirements first. Plotting-specific imports
include NumPy, pandas, SciPy, Matplotlib, scikit-learn, PyTorch,
Transformers, RDKit, joblib, safetensors, and tqdm.

## Provenance and reproducibility

See `FIGURE_MAP.csv` for figure-to-script mappings and `PROVENANCE.md` for the
source notebook records. Source notebooks are not distributed in this
repository.

Run scripts from the repository root or set `AEM_RL_ROOT` explicitly. Do not
commit generated images or model files unless they are required as release
assets. Record the input-data version and software environment for every export.
